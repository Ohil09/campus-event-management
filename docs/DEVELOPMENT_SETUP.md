# Development Environment Setup

This document explains how to set up the Campus Event Management System for local development.

---

## 1. Required Software

Each team member should install the following software:

- Git
- Visual Studio Code
- XAMPP 8.2.12 

XAMPP provides:

- Apache Web Server
- PHP
- MariaDB
- phpMyAdmin
